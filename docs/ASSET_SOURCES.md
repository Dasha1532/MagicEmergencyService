## Экран сотрудников

Файл `assets/ui/personnel_department_background.png` с первоначальным фоном кадрового отдела сгенерирован в ChatGPT для проекта 16 сентября 2026 года. Нейтральная рабочая версия `assets/ui/personnel_department_background_neutral.png` сохраняет исходную геометрию 1600×900, но содержит пять открытых кадровых рамок. Пустые рамки и области личного дела предназначены для заполнения портретами и текстом средствами Godot.

Файл `assets/ui/candidate_clasp.png` с кожаной застёжкой, латунным замком и восковой печатью сгенерирован в ChatGPT как отдельный PNG с прозрачным альфа-каналом. Godot показывает его поверх карточки ненанятого кандидата и скрывает после найма.

## Аварийный кран

Файлы `assets/objects/lava_faucet/faucet_normal.png`, `faucet_damaged.png` и `lava_stream.png` сгенерированы пользователем и переданы для игры 16 сентября 2026 года. Все три исходника имеют прозрачный альфа-канал. Варианты крана имеют одинаковый размер и предназначены для переключения состояний без смещения.

Файл `assets/backgrounds/bathroom_closeup.png` создан из переданного пользователем крупного фона ванной. Средствами встроенного ImageGen удалён нарисованный смеситель над ванной и восстановлена плитка, чтобы интерактивный кран можно было накладывать отдельным слоем. Остальная композиция комнаты сохранена.
